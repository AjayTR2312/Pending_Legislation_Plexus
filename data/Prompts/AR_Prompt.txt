TEXT DETECTION STRATEGY:
1. Analyze the PDF word-by-word to accurately detect all text
2. For each word, identify its exact position, formatting, and any styling (underline/strikethrough)
3. Reconstruct sentences by merging words in proper reading order
4. Handle split words or broken text by detecting word fragments and merging them correctly
5. Preserve word spacing and ensure no words are merged incorrectly or split incorrectly

CLEANING RULES (Apply to ALL pages):
1. Remove ALL line numbers (numbers at start or end of lines)
2. Remove ALL footers
3. Remove ALL page numbers

FORMATTING RULES (Apply PRECISELY):
CRITICAL: Only apply tags to text that is ACTUALLY underlined or has strikethrough in the document.
- Tag underlined text with [A>text<A]
- Tag strikethrough text with [D>text<D]
- Do NOT tag text that is only bold or only italic
- Do NOT tag regular text without underline/strikethrough

TAG APPLICATION RULES (Word-Level Precision):
1. Examine EACH WORD individually for underline/strikethrough formatting
2. Apply tags ONLY to the exact words that have the formatting
3. If only 3 words in a sentence are underlined, tag ONLY those 3 words
4. If half a line is underlined, tag ONLY that half
5. Do NOT extend tags to words that are NOT underlined
6. Each tagged section must have both opening [A> and closing <A] or [D> and <D]
7. When multiple consecutive words have the same formatting, group them in ONE tag: [A>word1 word2 word3<A]

⚠️ CRITICAL TAGGING VERIFICATION (MANDATORY FOR EVERY TAG):
For EACH section you tag:
1. BEFORE TAGGING: Read the ENTIRE sentence (minimum 10 words before + target + 10 words after)
2. COPY mentally: Remember all the words before and after the target text
3. ADD THE TAG: Wrap ONLY the formatted text with [A>...<A] or [D>...<D]
4. IMMEDIATELY VERIFY: Are all words before the tag still there?
5. IMMEDIATELY VERIFY: Are all words after the tag still there?
6. If ANY word is missing → STOP and restore it immediately

⚠️ COMMON TAGGING FAILURE (YOU MUST AVOID):
❌ WRONG: "text1 text2 [A>target<A]" (dropped words after target)
✅ CORRECT: "text1 text2 [A>target<A] text3 text4" (all words preserved)

SPECIAL CASE - PARTIAL NUMBERING/SUBSECTIONS:
CRITICAL: Pay special attention to section numbers like (b)(1), (a)(2), etc.
- If ONLY the sub-number has formatting (e.g., only "(1)" is stricken but NOT "(b)"), then:
  * Keep the parent number OUTSIDE the tag: (b) [D>(1)<D] rest of text
  * Do NOT include the parent number in the tag
- If the ENTIRE numbering has formatting (e.g., both "(b)" and "(1)" are stricken), then:
  * Include both in the tag: [D>(b)(1)<D] rest of text
- Examine the formatting of EACH component separately: (b), (1), (A), etc.
