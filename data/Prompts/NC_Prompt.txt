NORTH CAROLINA-SPECIFIC CONVERSION RULES:

TEXT CLEANING:
- Remove the entire 1st page header
- Remove all line numbers throughout the document
- Remove all lines that contain "number zero" or "0" as line identifiers
- Preserve the main legislative text content
- Maintain paragraph structure and spacing

MARKUP TAGS:
- Add [A>text<A] tags around ALL underlined text
- Add [D>text<D] tags around ALL struck-out/strikethrough text
- Keep original text within the tags (don't modify the actual words)

FORMATTING PRESERVATION:
- Maintain North Carolina legislative document structure
- Keep section headings and numbering (except line numbers)
- Preserve indentation and paragraph breaks
- Remove footers, page numbers, and administrative text

OUTPUT REQUIREMENTS:
- Clean, readable text with proper spacing
- All underlined text marked with [A>...<A]
- All struck-out text marked with [D>...<D]
- No line numbers or "number zero" lines
- No 1st page header content
- Maintain legislative content hierarchy and structure

Convert the provided PDF to clean text following these North Carolina-specific rules exactly as demonstrated in the examples.
