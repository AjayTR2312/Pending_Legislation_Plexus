FLORIDA LEGISLATIVE FORMATTING RULES (CRITICAL):
===================================================================

1. **Bill Title Section**:
   - "A bill to be entitled"
   - Blank line
   - "An act relating to..."
   - No blank line between title and act description (continuous text)
   - Example:
   ```
   A bill to be entitled
   
   An act relating to trusts; amending s. 736.04117, F.S.; revising the definition...
   ```

2. **Enacting Clause**:
   - Blank line before "Be It Enacted"
   - Example:
   ```
   ...effective upon becoming a law.
   
   Be It Enacted by the Legislature of the State of Florida:
   ```

3. **Section Headings** - Format: "Section 1.", "Section 2.", etc.
   - Blank line before section heading
   - No blank line after section heading (flows into text)
   - Example:
   ```
   (previous content)
   
   Section 1. Subsection (4) of section 736.04117...
   ```

4. **Subsection Structure** - Format: (1), (2), (3), etc.
   - Each subsection on its own line
   - BLANK LINE after each subsection
   - Example:
   ```
   (1) DEFINITIONS.-- For purposes of this section, the term:
   
   (a) "Authorized trustee" means...
   
   (b) "Qualified beneficiary" means...
   
   (2) DISTRIBUTION FROM A TRUST.--
   
   (a) Text of paragraph a...
   ```

5. **Lettered Items** - Format: (a), (b), (c), etc.
   - Each item on its own line
   - BLANK LINE after each lettered item
   - Example:
   ```
   (a) An authorized trustee...
   
   (b) A qualified beneficiary...
   
   (c) The settlor...
   ```

6. **Numbered Sub-items** - Format: 1., 2., 3., etc.
   - Each sub-item on its own line
   - BLANK LINE after each numbered sub-item
   - Example:
   ```
   1. The first condition...
   
   2. The second condition...
   
   3. The third condition...
   ```

7. **Paragraph Continuity**:
   - Join wrapped lines within same paragraph/sentence
   - Remove artificial line breaks from PDF wrapping (text wrapped at ~50-80 characters)
   - Maintain natural paragraph breaks (blank lines between distinct sections)
   - Example:
     * WRONG: "otherwise, an authorized trustee who has absolute\npower under the terms"
     * RIGHT: "otherwise, an authorized trustee who has absolute power under the terms"

8. **Spacing Rules Summary**:
   - Section headings (Section 1, Section 2): BLANK LINE before, NO blank line after
   - Subsections (1), (2), (3): BLANK LINE after each
   - Lettered items (a), (b), (c): BLANK LINE after each
   - Numbered sub-items 1., 2., 3.: BLANK LINE after each
   - Title section: BLANK LINE between "A bill to be entitled" and act description
   - Enacting clause: BLANK LINE before "Be It Enacted"
