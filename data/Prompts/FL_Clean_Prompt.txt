FLORIDA LEGISLATIVE FORMATTING RULES (CRITICAL):
===================================================================

1. **Bill Title Section**:
   - Sponsor line: "By Senator [Name]" or "By Representative [Name]" or "By the Committee on [Name]"
   - Blank line
   - "A bill to be entitled"
   - Blank line
   - "An act relating to..."
   - No blank line between title and act description (continuous text)
   - Example:
   ```
   By Senator Rodriguez

   A bill to be entitled
   
   An act relating to trusts; amending s. 736.04117, F.S.; revising the definition...
   ```

2. **Enacting Clause**:
   - Blank line before "Be It Enacted"
   - Example:
   ```
   ...effective upon becoming a law.
   
   Be It Enacted by the Legislature of the State of Florida:
   ```

3. **Section Headings** - Format: "Section 1.", "Section 2.", etc.
   - Blank line before section heading
   - No blank line after section heading (flows into text)
   - Example:
   ```
   (previous content)
   
   Section 1. Subsection (4) of section 736.04117...
   ```

4. **Subsection Structure** - Format: (1), (2), (3), etc.
   - Each subsection on its own line
   - BLANK LINE after each subsection
   - Example:
   ```
   (1) DEFINITIONS.-- For purposes of this section, the term:
   
   (a) "Authorized trustee" means...
   
   (b) "Qualified beneficiary" means...
   
   (2) DISTRIBUTION FROM A TRUST.--
   
   (a) Text of paragraph a...
   ```

5. **Lettered Items** - Format: (a), (b), (c), etc.
   - Each item on its own line
   - BLANK LINE after each lettered item
   - Example:
   ```
   (a) An authorized trustee...
   
   (b) A qualified beneficiary...
   
   (c) The settlor...
   ```

6. **Numbered Sub-items** - Format: 1., 2., 3., etc.
   - Each sub-item on its own line
   - BLANK LINE after each numbered sub-item
   - Example:
   ```
   1. The first condition...
   
   2. The second condition...
   
   3. The third condition...
   ```

7. **Paragraph Continuity**:
   - Join wrapped lines within same paragraph/sentence
   - Remove artificial line breaks from PDF wrapping (text wrapped at ~50-80 characters)
   - Maintain natural paragraph breaks (blank lines between distinct sections)
   - Example:
     * WRONG: "otherwise, an authorized trustee who has absolute\npower under the terms"
     * RIGHT: "otherwise, an authorized trustee who has absolute power under the terms"

8. **Spacing Rules Summary**:
   - Section headings (Section 1, Section 2): BLANK LINE before, NO blank line after
   - Subsections (1), (2), (3): BLANK LINE after each
   - Lettered items (a), (b), (c): BLANK LINE after each
   - Numbered sub-items 1., 2., 3.: BLANK LINE after each
   - Title section: BLANK LINE between "A bill to be entitled" and act description
   - Enacting clause: BLANK LINE before "Be It Enacted"

FLORIDA TABLE LAYOUT — COLUMN-ALIGNED FORMAT (CRITICAL)
===================================================================

Florida bills include the **OFFENSE SEVERITY RANKING CHART** under
section 921.0022, F.S., and similar statute reference tables.  These
tables MUST be rendered in column-aligned multi-line format that mirrors
the original PDF page layout — NOT collapsed onto a single line.

EXACT COLUMN POSITIONS (use space characters, never tabs):

  Column 1 — Florida Statute      starts at column  0   (width 36)
  Column 2 — Felony Degree        starts at column 36   (width 30)
  Column 3 — Description          starts at column 66   (continues to end)

LAYOUT RULES:

1. **Header row** — emit the column titles split across TWO lines so that
   "Florida" sits above "Statute" and "Felony" sits above "Degree":

   ```
   Florida                             Felony                        Description
   Statute                             Degree
   ```

   Insert ONE blank line before this header and ONE blank line after.

2. **Data rows** — every row begins with the statute reference at column
   0, the felony degree at column 36, and the description at column 66.
   Pad with spaces so each column starts at its exact position.

3. **Description wrapping** — when the description text wraps to a
   second (or third, fourth…) line, indent each continuation line to
   column 66 with spaces.  Each continuation line begins on its own
   physical line.

4. **Statute reference wrapping** — when the statute reference itself
   wraps (e.g. ``322.212`` then ``  (1)(a)-(c)`` on the next line), the
   continuation indents 2 spaces from column 0:

   ```
   322.212                             3rd                           Possession of forged, stolen,
     (1)(a)-(c)                                                      counterfeit, or unlawfully
                                                                     issued driver license;
                                                                     possession of simulated
                                                                     identification.
   ```

5. **Blank line between rows** — insert ONE blank line BETWEEN data
   rows so each row visually separates from the next.

6. **Tagged cells** — when a deletion tag covers a multi-line cell, emit
   a SEPARATE tag pair on EACH visual line.  Do NOT span the tag across
   the line break.  Example (deleted statute reference):

   ```
   [D>316.1935(1)                      3rd                           Fleeing or attempting to elude<D]
                                                                     [D>law enforcement officer.<D]
   ```

   The same rule applies to ``[A>...<A]`` additions covering wrapped cells.

7. **Section-letter sub-headers** — sub-headers like ``(a) LEVEL 1``,
   ``(b) LEVEL 2``, ``(c) LEVEL 3``…  appear on their OWN line with one
   blank line before and one blank line after (NOT inside the table grid).
