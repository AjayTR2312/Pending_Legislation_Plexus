TEXT DETECTION STRATEGY:
1. Analyze the PDF word-by-word to accurately detect all text
2. For each word, identify its exact position, formatting, and any styling (underline/brackets)
3. Reconstruct sentences by merging words in proper reading order
4. Handle split words or broken text by detecting word fragments and merging them correctly
5. Preserve word spacing and ensure no words are merged incorrectly or split incorrectly

CONNECTICUT CLEANING RULES (Apply to ALL pages):
1. Remove ALL line numbers (numbers at start or end of lines)
2. Remove ALL page numbers
3. Remove ALL footers
4. Remove ALL headers starting from page 2 (keep page 1 header if it contains bill information)
5. Keep main bill title, sponsor information, and legislative session information on page 1

CONNECTICUT FORMATTING RULES (Apply PRECISELY):
CRITICAL: Only apply tags to text that is ACTUALLY underlined or in brackets in the original PDF.
- ONLY tag underlined text with [A>text<A]
- ONLY tag text enclosed in brackets with [D>text(with brackets)<D] you can refer in example files how they ahve added.

CONNECTICUT TAG APPLICATION RULES (Word-Level Precision):
1. Examine EACH WORD individually for underline formatting or bracket enclosure
2. Apply [A>...<A] tags ONLY to the exact words that are underlined
3. Apply [D>...<D] tags ONLY to text that appears with brackets [ ] in the original
4. If only 3 words in a sentence are underlined, tag ONLY those 3 words
5. If text is both underlined AND in brackets, prioritize bracket tagging [D>...<D]
6. Do NOT extend tags to words that are NOT underlined or bracketed
7. Each tagged section must have both opening [A> and closing <A] or [D> and <D]
8. When multiple consecutive words have the same formatting, group them in ONE tag: [A>word1 word2 word3<A]

CONNECTICUT BRACKET DETECTION:
9. Look for text enclosed in square brackets [ ] or other bracket types
10. Tag the content INSIDE the brackets, not the brackets themselves: [text] becomes [D>[text]<D]
11. If brackets contain multiple words: [word1 word2] becomes [D>[word1 word2]<D]
12. Handle partial bracketing carefully - only tag what's actually within brackets

SPECIAL CASE - PARTIAL NUMBERING/SUBSECTIONS:
CRITICAL: Pay special attention to section numbers like (b)(1), (a)(2), etc.
- If ONLY the sub-number is underlined or bracketed (e.g., only "(1)" is underlined), then:
  * Keep the parent number OUTSIDE the tag: (b) [A>(1)<A] rest of text
- If the ENTIRE numbering is underlined or bracketed, then:
  * Include both in the tag: [A>(b)(1)<A] rest of text
- Examine the formatting of EACH component separately: (b), (1), (A), etc.

TEXT REFLOW RULES:
1. Merge lines that are part of the same paragraph into continuous text
2. Remove artificial line breaks from PDF page width
