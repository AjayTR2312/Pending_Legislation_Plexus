INDIANA CLEANING RULES (Apply to ALL pages):
1. Remove ALL line numbers (numbers at start or end of lines)
2. Remove ALL page numbers that appear in headers
3. Remove ALL footers
4. Keep the main document content and legislative structure
5. Preserve bill titles, sponsor information, and session details

INDIANA FORMATTING RULES (Apply PRECISELY):
CRITICAL: Only start applying tags from "SECTION 1" onward in the document.
- ONLY tag bold text with [A>text<A] starting from "SECTION 1"
- ONLY tag strikeout text with [D>text<D] starting from "SECTION 1"
- DO NOT tag any formatting that appears before "SECTION 1"

INDIANA TAG APPLICATION RULES (Starting from "SECTION 1"):
1. Examine EACH WORD individually for bold or strikeout formatting
2. Apply [A>...<A] tags ONLY to the exact words that are bold
3. Apply [D>...<D] tags ONLY to the exact words that have strikeout formatting
4. If only 3 words in a sentence are bold, tag ONLY those 3 words
5. If half a line has strikeout, tag ONLY that half
6. Do NOT extend tags to words that are NOT bold or struck out
7. Each tagged section must have both opening [A> and closing <A] or [D> and <D]
8. When multiple consecutive words have the same formatting, group them in ONE tag: [A>word1 word2 word3<A]

INDIANA SPECIAL RULES:
9. START tagging only when you reach "SECTION 1" in the document
10. Everything before "SECTION 1" should be cleaned but NOT tagged
11. Pay attention to section numbers, subsection numbers that may be bold
12. Look for struck-out amendments and deletions in the legislative text

SPECIAL CASE - PARTIAL NUMBERING/SUBSECTIONS (After "SECTION 1"):
CRITICAL: Pay special attention to section numbers like (b)(1), (a)(2), etc.
- If ONLY the sub-number is bold or struck out (e.g., only "(1)" is bold), then:
  * Keep the parent number OUTSIDE the tag: (b) [A>(1)<A] rest of text
- If the ENTIRE numbering is bold or struck out, then:
  * Include both in the tag: [A>(b)(1)<A] rest of text
- Examine the formatting of EACH component separately: (b), (1), (A), etc.
