   - Blank line before "Be it enacted"
   - Example:


3. **Section Headings** - Format: "SECTION 1.", "SECTION 2.", etc.
   - Blank line before section heading
   - No blank line after section heading (flows into text)
   - Example:
   ```
   (previous content)
   
   SECTION 1. In Colorado Revised Statutes, 39-22-104, add (4)(dd) as follows:
   ```

4. **Colorado Revised Statutes (C.R.S.) References** (PRESERVE EXACTLY):
   - Format: "39-22-104"
   - With subsections: "39-22-104 (4)(dd)"
   - With letters: "39-22-104 (4)(dd)(I)"
   - Never remove hyphens or change formatting
   - Example:
   ```
   SECTION 1. In Colorado Revised Statutes, 39-22-104, add (4)(dd) as follows:
   ```

5. **Subsection Structure** - Format: (1), (2), (3), etc.
   - Each subsection on its own line
   - BLANK LINE after each subsection
   - Example:
   ```
   (1) This subsection (4)(dd) applies to income tax years commencing...
   
   (2) A taxpayer may claim a credit against the tax...
   
   (3) The amount of the credit allowed...
   ```

6. **Lettered Items** - Format: (a), (b), (c), etc.
   - Each item on its own line
   - BLANK LINE after each lettered item
   - Example:
   ```
   (a) The taxpayer is a manufacturer...
   
   (b) The taxpayer has increased employment...
   
   (c) The taxpayer has made capital investments...
   ```

7. **Addition Tags [A>...<A]** - Colorado uses ALL CAPS for added text:
   - Text flows continuously within tags
   - Remove artificial line breaks from PDF wrapping
   - Example:
   ```
   WRONG (artificial breaks):
   [A>FOR INCOME TAX YEARS COMMENCING ON OR AFTER
   JANUARY 1, 2027<A]
   
   CORRECT (flowed text):
   [A>FOR INCOME TAX YEARS COMMENCING ON OR AFTER JANUARY 1, 2027<A]
   ```

8. **Deletion Tags [D>...<D]** - Strikethrough text:
   - Preserve exactly as written
   - Example:
   ```
   [D>old provision<D]
   ```

9. **Repeal Clauses** (PRESERVE COMPLETELY):
   - Format: "THIS SUBSECTION (4)(dd) IS REPEALED, EFFECTIVE..."
   - All content about repeal dates and conditions
   - Example:
   ```

   ```

10. **Text Reflow** - Remove artificial line breaks:
    - Join lines that are part of same sentence
