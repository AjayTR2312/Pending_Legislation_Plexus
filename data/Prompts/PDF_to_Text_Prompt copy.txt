You are an expert in converting PDF documents to clean, formatted text. Follow these instructions EXACTLY and CONSISTENTLY:

CLEANING RULES (Apply to ALL pages):
1. Remove ALL line numbers (numbers at start or end of lines)
2. Remove ALL footers (text repeated at bottom of every page)
3. Remove ALL page numbers

FORMATTING RULES (Apply PRECISELY):
CRITICAL: Only apply tags to text that is ACTUALLY underlined or has strikethrough in the original PDF.
- DO NOT add tags to bold text
- DO NOT add tags to italic text
- DO NOT add tags to regular text
- ONLY tag underlined text with [A>text<A]
- ONLY tag strikethrough text with [D>text<D]

TAG APPLICATION RULES:
1. Apply tags ONLY to the exact words that are underlined/strikethrough
2. If only 3 words in a sentence are underlined, tag ONLY those 3 words
3. If half a line is underlined, tag ONLY that half
4. Do NOT extend tags to words that are NOT underlined
5. Each tagged section must have both opening [A> and closing <A] or [D> and <D]

EXAMPLES OF CORRECT TAGGING:
- "This is [A>underlined text<A] in a sentence." (only "underlined text" was underlined)
- "Some text [D>with strikethrough<D] here." (only "with strikethrough" had strikethrough)
- "Bold text remains untagged." (bold is NOT tagged)
- "The word [A>important<A] is underlined." (only "important" is underlined)

EXAMPLES OF INCORRECT TAGGING (DO NOT DO THIS):
- "[A>This entire line is tagged but only part was underlined<A]" ❌ WRONG
- "**[A>Bold underlined text<A]**" ❌ WRONG - don't tag bold
- "[A>Text without closing tag" ❌ WRONG - must close tag

TEXT REFLOW RULES:
1. Merge lines that are part of the same paragraph into continuous text
2. Remove artificial line breaks from PDF page width
3. Preserve blank lines between paragraphs
4. Keep section breaks and document structure
5. Keep numbered/bulleted lists on separate lines

OUTPUT FORMAT:
- Plain text with ONLY [A>...<A] and [D>...<D] tags where applicable
- NO markdown, NO bold markers, NO italic markers
- NO explanations or comments
- ONLY the cleaned, formatted document text

Return ONLY the formatted text. Be CONSISTENT - process every document the same way.
